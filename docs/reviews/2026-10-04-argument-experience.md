# Connected reads, validation and sourced arguments

The user reported the sender-account TRANSPORT failure with connected MetaMask, missing required-field feedback, an undiscoverable contract chooser, stacked focus outlines and guesswork in arguments. Changes stay generic across supported imported ABIs. Audio remains excluded.

## Reproduced causes and repairs

1. **Unintended caller:** the form passed the connected address to every read. In actual Zen with the user's already connected MetaMask, a factory getter reproduced the reported failure. Ordinary browser and assistant reads now omit `from`; an explicit caller override remains for caller-scoped state. Writes and simulation retain their intended sender. A live `factory()` read completed in that same connected Zen session after the repair.
2. **Development error identity:** a Runtime retained across module reloads can throw errors from an older WorkbenchError class. The formatter now preserves those known errors rather than downgrading PRECONDITION to TRANSPORT. The dev runtime is replaced when its class changes. Account guidance explains selected-network registration; no funding or resend is automated.
3. **Bundled ABI mismatch discovered manually:** `WETH()` reverted on the actual router. The [official SaucerSwap source](https://github.com/saucerswaplabs/saucerswap-periphery/blob/606a00316c5526a8fb42c35a5692d8f8bdb97810/contracts/UniswapV2Router02.sol#L18) exposes `whbar()` as the token address getter. Corrected the bundled/example ABI and verified direct RPC/core equality on both networks. The resulting ABI revision changes invalidate old bundled review context; imported local ABIs are not rewritten. No wrapping/allowance operation is added.

## Shared argument experience

Browser-safe core exports provide one codec for UI and execution. Missing values, nested tuple fields, array elements, malformed addresses and exact integer bounds have canonical paths. Every independent error is collected before submission, displayed inline with invalid semantics and red borders; the form focuses the first invalid control. ABI-valid empty strings/bytes/arrays and false/zero stay valid, with explicit empty-value controls for untouched inputs. Group errors link to their fieldsets. Caller and HBAR fields validate before RPC. Caller disclosure remains open while fixing errors.

The contract selector has a visible label, border and dropdown indicator. Inputs, selectors and picker search use a single focus treatment within the existing Slush palette and installed primitives. No UI dependency was added. 21st references were searched; none needed to be copied. Final deterministic review has zero errors, one existing width warning and two existing color-token suggestions; actual narrow layouts do not overflow.

**Find a value** lists compatible read getters from the selected ABI, including full signatures and required inputs. It reads only an explicitly chosen getter, validates actual returned values against the target type/bounds and exposes source function, result path, network, time and ABI revision. Applying a result is explicit and invalidates old results/reviews. Results are bounded to 64 choices/4,096 visited nodes; abandoned requests are cancelled. Reading inside the dialog does not submit the outer target form.

Core inspection, actual CLI/MCP inspection, assistant inspection and portable agent context all include the same `inputSources`. The skill remains contract-independent. A count is not an enumeration; matching types are not proof of existing IDs or semantic intent. The workbench does not invent token/proposal IDs, units, routes, recipients or votes. If the ABI offers no discoverable getter, the developer/agent needs authoritative input or a fuller ABI. This adds no contract categories or event indexing.
